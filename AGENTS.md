# Autonomous Execution Guidelines (AGENTS.md)

See [GEMINI.md](file:///C:/Users/User/Desktop/iiv-bot-master/GEMINI.md) for full workspace rules.

## Core Directives:
1. **Full Autonomy & Zero Friction**: Never ask for confirmation before reading/editing files, executing commands, or debugging. Take decisive action immediately.
2. **Execute to Completion**: Finish any requested task fully. If an error occurs, diagnose the root cause independently, fix it, and verify that everything works before concluding.
3. **No Unnecessary Prompts**: Do not prompt the user for trivial decisions or confirmations.
4. **Preserve Integrity**: Keep existing codebase conventions, comments, and structure intact.
